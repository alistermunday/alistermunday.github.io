# alistermunday.github.io

Source for [alistermunday.com](https://alistermunday.com).

## What this is

A personal, growing set of pages — refresh the tab instead of scrolling old chats.
Plain static HTML/CSS, no build step, no Jekyll (see `.nojekyll`). `index.html` is
the hub; every new page gets a card there.

## Adding a page

1. Write the `.html` file at repo root.
2. Add a card for it in `index.html`.
3. Commit, push. GitHub Pages serves it as-is (no build step).

## Legacy

`lab/_legacy-axioms-site/` holds an earlier Jekyll scaffold for the Axioms of
Description / Coherence Framework publication site, parked (not deleted) when
this repo's root was repurposed for the personal notebook. Revive it under a
subpath later if wanted — nothing was lost.
